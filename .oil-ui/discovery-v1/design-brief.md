# Skills Discovery V1

- 北极星：让用户在安装前先判断可信度与适配性，而不是被 Stars 推着走。
- 用户：正在为 Codex 寻找第三方 Skill 的开发者和创作者。
- 主视口：1440×1024 桌面；390×844 手机作为检查视口。
- 主角：可筛选的 GitHub Skill 仓库与精确 `SKILL.md`。
- 主动作：打开 Skill 详情并复制 Codex 安装指令。
- 范围：纯静态 GitHub Pages；GitHub Actions 定时生成索引与详情 JSON，浏览器不直接请求 GitHub API、不连接本地服务、不写本机文件。
- 视觉方向：开源目录编辑部；纸白底、深蓝黑文字、酸橙绿主动作、编号与粗线建立秩序。
- 关键状态：静态索引加载、结果、空索引、空结果、仓库详情、Skill 内容预览、复制完成、中英切换。
- 筛选边界：仓库语言取自 GitHub 的主要代码语言；国家不是仓库属性，维护者地区由定时任务根据公开 Profile 推测。
- 分类：代码开发、原型设计、需求分析、视频剪辑、文案撰写、自媒体运营、人力资源管理、其他；英文按同一分类键展示。
- 页面结构：删除宣传首屏与安装方法区，首屏直接进入搜索、筛选和目录结果。
- 动效：搜索按钮按压、筛选结果重排、详情抽屉滑入；尊重减少动态效果。
- 验收：无需前端构建即可部署；分类与 Stars 筛选、中英切换、静态仓库详情、SKILL.md 预览、复制安装指令可用。
- 评审：当前环境不允许独立子 Agent，采用主 Agent 自检并明确标注。
